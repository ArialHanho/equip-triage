# Release checklist

- Include code, original synthetic fixtures, reproducible benchmark summaries, docs, notebooks, and the code license.
- Keep internal unit-test sources out of the public snapshot. Publish executable benchmark commands and measured results.
- Exclude credentials, runtime paths, checkpoints, databases, company data, and third-party dataset archives.
- Inspect notebook outputs and execution metadata before publication.
- Report split definitions, sample counts, data provenance, runtime and known failure modes. Do not infer industrial yield gains.
- Preserve existing remote history and verify files after publication.
- See [contribution guide](CONTRIBUTIONS.md) for attribution.
