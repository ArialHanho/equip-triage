# Frozen candidate-state challenge

## Question and primary endpoint

Can a shared reader for each recorded candidate distinguish a memo with one continuing issue from the same memo with two? The primary endpoint is the fraction of matched one/two pairs with **both routing decisions correct**, at validation-selected utility thresholds, separately for English and Korean. Within each family, the first unordered equipment pair contributes continuing/cleared vs continuing/continuing, and the second contributes cleared/continuing vs continuing/continuing. Each of seven surface/order views contributes once. The same physical scenario underlies multiple views, so uncertainty is clustered by whole family. Secondary endpoints include triple success on both single-cause directions and the two-cause case, and five-class macro-F1.

The previous private memo study provided the motivation. None of its evaluation files, templates or scores enters training, calibration or the new test. This is a new author-designed synthetic challenge, not an independently written blind test. The row generator, split wording, this protocol and canonical serialized split fingerprints are locked before model fitting. Validation thresholds, method selection and training-source hashes are written before the first challenge scoring pass. The challenge is scored once for the official study. Reproduction after release is a replay of a public benchmark.

## Observations and integrity

Each packet has two ordered equipment check records (domain ID and registry tag) and at most two lines of memo text. A line can identify a registered tag or a documented ordinal expression. The matcher uses only those observed fields. More/fewer than two distinct valid domains/tags, a missing line, or non-bijective binding makes the packet incomplete for routing. Scoped methods use the same binder. Include a flat direct comparator before and after this integrity check and candidate membership mask. All methods operate on identical packets and can recover the same field features. A subject may be identifiable while its latest result remains unknown; those examples pass the integrity check.

The three candidate states are continues, cleared and unknown. The decision rule routes only if exactly one candidate continues and the other is cleared. Two continuing candidates, no continuing candidate, or an unknown state yield hold. For two withheld outcomes, the identical visible memo is compatible with continues/cleared or cleared/continues. Both possible actionable completions must be withheld. The generator assigns decision labels independently of the decoder.

Twelve training, four validation and eight challenge wording families are disjoint. Each family covers all four categories in two pairs, both languages and independent interventions on registry aliases, event order and line order. All variants of a situation and its translations stay together. The release includes the original synthetic generator and phrase tables under the repository license. Individual rows can be regenerated offline. No real customer, factory or third-party corpus is used.

## Comparisons fixed before training

1. A scoped bilingual rule resolves references, applies negation, retest and latest-observation patterns, then counts continuing candidates. A gold-state oracle tests the expressiveness of the decoder.
2. Character 2–5 gram TF-IDF and logistic regression (C=4). Compare direct packet labels, mention-ordered factor heads with a fixed join, and a shared candidate-state classifier with global or restricted evidence. Direct scores also get the identical integrity/membership check. Compare a winner-take-all decoder and the exactly-one decoder on the same restricted state scores. Disclose feature and annotation differences.
3. Scratch BERT-family encoders use the repository's explicit scaled-QKV blocks, two layers, width 32, four heads. Compare a standard flat direct classifier, direct classification on two locally encoded clauses, global classification of the two candidate states from clause CLS states, and a shared three-state head. In the shared-head arms cross two interventions: all vs bound evidence, uniform vs learned attention weights. Keys and values come from clause-local contextual tokens; no token from the other clause enters the bound pooled evidence. Candidate/domain header information remains available to every arm. The learned weights use candidate queries and four heads of dimension eight. Report the exact-count and winner-take-all ablation on identical bound-query scores. All common weights start the same within a seed. Direct methods receive action labels; structured methods additionally receive generator-supplied state labels.
4. A byte-level BPE fitted only on unique training text. Twelve epochs, batch 64, AdamW at 0.002, training seeds 41/42/43, one PyTorch compute thread, no pretrained weights or MLM. All model choices, epochs and threshold grid are fixed before viewing the challenge output. Report one-row warm CPU latency separately from fitting and process startup.

## Gates and statistics

Grid: 0, .25, .40, .55, .70, .85, .95, 1.01. Confidence below the cutoff yields hold. The utility gate maximizes the mean of EN/KO five-class macro-F1 on validation. Break ties by fewer released gold holds, fewer wrong checks, then higher threshold. The risk gate maximizes correct routed checks subject to released gold holds at or below 10% of all gold holds in **each** validation language, with the same tie breakers. Report actual test coverage (checks / all rows), gold holds routed / all gold holds, and errors among routed checks. Also report risk on structurally valid packets, so easy integrity holds cannot obscure semantic mistakes. Default inference method maximizes mean validation utility macro-F1 over its fixed seeds; simpler method wins an exact tie. Oracle excluded.

For all methods report both-correct counts on primary pairs, header swaps that change a positional route, header/line permutations that should preserve the decision, named aliases replaced by unseen but listed tags, persistent vs cleared retests, persistent vs unavailable results, and multi-cause triples. Report incomplete and semantically unanswerable outcomes. Record primary, raw and risk-gated confusion counts. Measure candidate-state accuracy for valid packets separately.

Estimate 95% paired percentile intervals on primary pair success and macro-F1 changes with 2,000 whole-family bootstrap samples (seed 1783); all translations, substitutions and both members of each pair travel together. Recompute pooled metrics for each draw and average over the three fixed initialization seeds for neural arms. Include restricted vs global support, learned vs uniform weights on restricted support, restricted query vs structured character model, candidate vs mention formulation, direct vs structured BERT, and hard count vs winner-take-all. Also report the decoder-only change at zero confidence threshold. These conditional intervals exclude uncertainty from new writers, data-generating processes, seed sampling and unmeasured deployment conditions.
